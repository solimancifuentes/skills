# Customize a Framer template

Adapt an existing Framer template to a business or project while retaining its components, styles, and responsive behavior.

## Installation

```sh
npx skills add solimancifuentes/skills --skill customize-framer-template
```

## Process

1. Confirm the project and inspect the pages, shared components, and CMS relationships affected by the request.
2. Map verified business facts to the existing content and design. Identify unsupported claims, missing assets, and unresolved destinations.
3. Apply changes covered by the request, reusing the template's structure and preserving content and styles outside scope.
4. Read back the changes and check affected layouts, links, and responsive states. Report what changed, what was checked, and what remains unresolved.

## What to provide

Provide the project or relevant source material, the pages or changes you want, and the business facts and assets the site may use. The skill preserves wording you have fixed. Delegated copywriting can proceed from verified facts without a separate approval for each text block.

Planning, factual briefs, and content maps work without a live connection. Live project inspection and edits need an authorized Framer environment with the required capabilities. Named helper skills are optional integrations.

## Preserve the working template

The workflow covers partial changes as well as full customization. It prefers reversible hiding and reuse, keeps customer evidence authentic, and checks affected pages and components after shared changes. Publishing, deletion, and external-service changes need authority that covers those effects. If an edit's result is unclear, the project state is inspected before retrying.
