# Anti-Slop Editor

Revise prose to remove filler, inflated language, and distracting rhetorical habits while preserving the meaning and intended voice.

## Installation

```sh
npx skills add solimancifuentes/skills --skill anti-slop-editor
```

## Process

1. Read the full passage and editing request to establish its purpose, audience, and tone.
2. Revise wording and structure where they obscure the point, repeat it without purpose, or make unsupported claims sound stronger.
3. Compare the revision with the original to preserve facts, conditions, uncertainty, and protected text.
4. Return the revised text first, with a brief note only when a material gap or unresolved issue needs attention.

## What to provide

Supply the draft and any requirements for audience, length, tone, or house style. Identify wording that must remain exact. Quotations, code, identifiers, and link destinations stay intact unless you ask to edit them.

The default output is the finished revision. You can also request an explanation of the changes or a different format.

## Keep the voice

Punctuation, heading styles, and emojis are editorial choices. The current assignment, selected voice, and language conventions take precedence over this skill's defaults. Purposeful fragments, metaphors, and humor can remain when they serve the writing.

The editor preserves necessary qualifications and flags substantive gaps instead of filling them with invented details. Fact-checking is a separate task you can request alongside the edit. Editing alone establishes neither factual truth nor authorship, and the skill does not provide AI-detection scores.
