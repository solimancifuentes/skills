# Writing Style Profile

Create a reusable profile of an author's writing style, or use an existing profile to draft, revise, or evaluate new writing.

## Installation

```sh
npx skills add solimancifuentes/skills --skill writing-style-profile
```

## Process

1. Identify the intended audience, format, language, and sample sources.
2. Find recurring choices in structure, wording, rhythm, tone, and explanation, keeping context and exceptions visible.
3. Build the requested profile or apply an existing one to the current assignment.
4. Check content fidelity and style fit, and report what kind of evaluation was actually performed.

## Samples that help

Provide representative writing or an existing profile. The skill works from supplied or authorized samples. Include source labels and known information about collaboration, editing, translation, or AI assistance. Samples from several subjects help separate transferable habits from topic vocabulary.

Work starts with the available evidence. There is no minimum word count that guarantees a useful profile or successful imitation. Additional samples should address a specific gap, such as disagreement, long explanations, or informal replies. The [sampling guide](references/sampling-and-evaluation.md) explains these choices.

## What the result establishes

A profile distinguishes observed habits, tentative interpretations, and preferences requested for future writing. It preserves meaningful differences in dialect, register, and context. Profiles may include source excerpts; review them before sharing.

New writing uses the assignment's facts without borrowing source anecdotes or inventing biography. A style match cannot establish authorship or authenticity. Internal review, evaluation on material withheld from profile development, and author feedback are different levels of evidence; the skill reports those limits without promising a percentage match.
