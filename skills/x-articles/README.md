# X Articles

Draft and prepare long-form articles for X with formatting that serves the explanation. Start from a topic, source material or an existing draft, and deliver complete copy with useful headings, emphasis, tables, code, math, media or embedded posts where the subject calls for them.

The skill supports any topic and requested voice. It does not require technical subject matter, a fixed article structure, another writing skill, a particular model or provider-specific tools.

## Installation

```sh
npx skills add solimancifuentes/skills --skill x-articles
```

## Use it

> Use X Articles to adapt this essay for X. Preserve its voice and argument, add relevant post embeds if you can verify them, and provide both an inline version and a Markdown file.

> Use X Articles to write an article about starting a neighborhood seed library from these notes. Choose formatting that helps a first-time organizer follow the process.

> Use X Articles to explain the available formatting options and how to hand off an article for X's editor.

Specify the audience, language, length, protected wording, source requirements or desired delivery mode when they matter. The skill uses the supplied brief without requiring an intake form.

## How it works

1. Develop or preserve a supported argument in the requested voice.
2. Select formatting for its explanatory purpose, using a source-labeled inventory of documented and demonstrated X features.
3. Verify relevant post URLs, handles and assets when they are used, and place embeds beside the passages they inform.
4. Deliver the requested article and any necessary insertion notes, then check fidelity and the accessible preview.

Tables, code, math and media are optional. Platform recommendations do not impose a word-count reduction, heading cadence, compulsory question or call to action.

## Delivery and requirements

| Mode | Result | Capabilities |
| --- | --- | --- |
| Inline, the default | Complete formatted article with source links and verified standalone post URLs | Text and supplied material; browsing when verification is needed |
| Markdown artifact, when requested | Article file, with separate production notes only when native insertions need explanation | File writing; asset creation or retrieval only when needed and available |
| Native X draft, when requested | An actual editor draft with meaningful readback, or a clear handoff if editor access is unavailable | Authorized browser/editor access |

Formatting questions and review requests receive the requested explanation or findings. Publishing is a separate action. Markdown describes formatting intent; it is not a guarantee of automatic import into X. A preview demonstrates presentation, not measured engagement or reliable behavior across models.
